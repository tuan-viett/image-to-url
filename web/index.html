ImageURL là gì?

ImageURL là dịch vụ lưu trữ hình ảnh miễn phí dành cho developer và AI workflows. Thay vì phải tự host file trên server riêng, bạn chỉ cần upload một lần và nhận về một public URL ổn định, dùng được trong HTML, Markdown, Notion, Slack, GitHub README, email — bất kỳ đâu cần hiển thị ảnh.

Điểm khác biệt lớn nhất là ImageURL hiểu Base64 ngay từ đầu. Nếu bạn đang chạy pipeline AI tạo ảnh (Stable Diffusion, DALL-E, Midjourney, ComfyUI), output thường là chuỗi data:image/png;base64,... — không có URL. Paste vào ImageURL, bấm Convert, bạn có ngay URL HTTPS để dán vào Slack hay CMS mà không cần code thêm.

Cách sử dụng ImageURL

  1. Upload file — kéo thả hoặc chọn ảnh JPEG/PNG/WebP/GIF (tối đa 5 MB cho anonymous, 10 MB cho tài khoản đăng ký).
  2. Dán Base64 — copy chuỗi data:image/png;base64,... từ AI tool hoặc clipboard vào ô Paste Base64.
  3. Nhận public URL — ImageURL trả về HTTPS URL dạng https://img.example.com/i/abc123def.png ngay lập tức. Copy và dùng.
  4. Quản lý qua Dashboard — đăng ký miễn phí để xem lại ảnh đã upload, xoá, tạo API key, xem usage analytics, mua gói Pro để tăng quota và retention.

Newsletter HTML cần ảnh hosted ở URL public ổn định (không phải blob local). CMS headless có thể gọi API ImageURL khi author upload ảnh để chuẩn hoá storage.

REST API cho developer

ImageURL cung cấp REST API đơn giản, dùng JWT (sau khi login) hoặc API key (sk_live_...) trong header Authorization.

Upload file qua multipart

curl -X POST https://img.example.com/api/v1/images \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -F "file=@/path/to/image.png"

# Response
{
  "success": true,
  "data": {
    "url": "https://img.example.com/i/abc123def.png",
    "storage_key": "abc123def",
    "expires_at": "2026-10-25T10:00:00Z"
  }
}

Upload Base64 qua JSON body

curl -X POST https://img.example.com/api/v1/images \
  -H "Authorization: Bearer sk_live_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgo..."}'

Chi tiết đầy đủ các endpoint (list images, delete, API key management, usage analytics) xem tại API Documentation trong dashboard.

Câu hỏi thường gặp

ImageURL có miễn phí không?

Có. Gói Free cho 20 lượt upload, file tối đa 5 MB, retention 3 ngày. Đăng ký tài khoản là dùng được ngay, không cần thẻ tín dụng.

Làm sao convert Base64 sang public URL?

Dán chuỗi data:image/png;base64,... vào ô Paste Base64 trên trang chủ, bấm Convert, hệ thống trả về URL HTTPS công khai. Hoặc gọi POST /api/v1/images với {"image": "data:image/png;base64,..."} qua API.

API có cần API key không?

API cho phép 2 chế độ xác thực: JWT token (sau khi login) hoặc API key sk_live_.... Tạo key trong dashboard → tab API Keys. Secret chỉ hiển thị 1 lần duy nhất khi tạo.

Upload anonymous giữ ảnh bao lâu?

Mặc định 24 giờ cho user anonymous (tự động xoá). User đăng ký có retention theo plan: Free 3 ngày, Basic 10 ngày, Pro 30 ngày. Mỗi lần nâng cấp / mua thêm plan sẽ cộng thêm lượt upload.

Có hỗ trợ AI workflows không?

Có. Endpoint POST /api/v1/images nhận multipart file hoặc JSON body chứa trường image (data:image/...;base64,...). Phù hợp để convert Base64 output từ Stable Diffusion, DALL-E, Midjourney, ComfyUI thành URL chia sẻ được.

File size và format giới hạn thế nào?

Hỗ trợ JPEG, PNG, WebP, GIF. Anonymous tối đa 5 MB / file. User đăng ký tối đa 10 MB / file. EXIF GPS bị strip trước khi lưu để bảo vệ privacy. Không hỗ trợ SVG (vì lý do bảo mật).
