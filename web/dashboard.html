API Documentation

Turn images into public URLs. Use your sk_live_... key to authenticate.

Base URL http://localhost
POST /api/v1/images JWT or API key

Convert an image (multipart)

Upload a binary file. The file field is required.

cURL

curl -X POST http://localhost/api/v1/images \
  -H "Authorization: Bearer sk_live_xxxxxxxxx" \
  -F "file=@/path/to/image.png"

Response 200

{
  "success": true,
  "data": {
    "id": 42,
    "url": "http://localhost/i/ab/cd/key.png",
    "mime_type": "image/png",
    "size": 12345,
    "created_at": "2026-09-24T08:00:00"
  }
}
POST /api/v1/images JWT or API key

Convert a Base64 image

Send a JSON body with image set to a raw Base64 string or a data:image/...;base64,... URI.

cURL

curl -X POST http://localhost/api/v1/images \
  -H "Authorization: Bearer sk_live_xxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgo..."}'

Response 200

{
  "success": true,
  "data": {
    "id": 43,
    "url": "http://localhost/i/ab/cd/key.png",
    "mime_type": "image/png",
    "size": 69,
    "created_at": "2026-09-24T08:00:00"
  }
}
INFO Error envelope

  "error": {
    "code": "FILE_TOO_LARGE",

    "details": { "max_bytes": 5242880 }
